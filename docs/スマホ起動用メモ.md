 Mana's Ballの同一Wi-Fi用pygbag試遊モードを起動してください。

1. 現在のPython環境とpygbagの導入状況を確認する。
2. ipconfigで現在のWi-Fi IPv4アドレスを取得する。
3. ポート8000の使用状況を確認する。
4. プロジェクト直下で次の形式によりpygbagを起動する。

python -m pygbag --bind <現在のWi-Fi IPv4アドレス> --port 8000 .
python -m pygbag --bind 192.168.1.5 --port 8000 .


5. HTTP 200とポートの待受状態を確認する。
6. PCとスマホで開くURLを報告する。
7. サーバーは終了せず、試遊できる状態で待機する。

コード変更、pygbagの更新、ファイアウォール変更、外部公開は行わないでください。
既存プロセスがポート8000を使用している場合は、内容を確認してから再利用または安全に再起動してください。
