# GitHub Copilot向けDirect Implementation運用

この文書は、Codex用の`direct-implementation` Skillと同等の直接実装フローを、GitHub Copilotを利用するリポジトリへ導入するための共通指示です。

## 導入するファイル

他のリポジトリへ、次のファイルを同じ相対パスでコピーします。

```text
.github/copilot-instructions.md
docs/implementation/copilot-direct-implementation.md
docs/implementation/README.md
docs/implementation/current.md
```

Codexも併用する場合は、次もコピーします。

```text
.agents/skills/direct-implementation/SKILL.md
```

対象リポジトリに既存の指示ファイルがある場合は上書きせず、内容を統合します。プロジェクト固有の起動方法、テスト方法、データ・アセット・ログ・Git規則は、そのリポジトリの`AGENTS.md`やREADMEを優先します。

## Copilotへの依頼文

`docs/implementation/current.md`へ個別仕様書を貼り付けた場合は、次のように依頼します。

```text
Direct Implementationを使用し、docs/implementation/current.md全体を今回の仕様本文として、このリポジトリへ直接実装してください。
```

チャットへ直接貼り付ける場合は、次の形式を使用します。

```text
Direct Implementationを使用し、以下を今回の仕様本文として、このリポジトリへ直接実装してください。

ここに個別仕様書を貼り付ける。
```

## 仕様入力元

次の優先順位で今回の仕様を決定します。

1. 現在の依頼に直接記載された個別指示。
2. 現在の依頼へ貼り付けられた個別仕様書。
3. 現在の依頼で明示された仕様ファイル。
4. `docs/implementation/current.md`。
5. 適用範囲の`AGENTS.md`、README、既存仕様書。

選択した個別仕様書の全体を今回の仕様本文として扱います。別の実装指示書へ再変換せず、そのまま既存実装の調査と直接実装へ使用します。`current.md`が存在しない、空、または案内文だけの場合はコードやデータを変更せず、有効な仕様がないことを報告します。

## 共通の直接実装手順

1. 適用範囲の指示ファイル、README、起動・テスト方法を確認する。
2. 仕様中の画面名、機能名、状態名、表示文言、データ項目を検索し、初回3～8ファイル程度へ調査を絞る。
3. 現在の処理経路、既存処理との接続点、再利用対象、変更範囲、確認方法を整理する。
4. 停止条件に該当しなければ、追加回答を待たず既存方式を再利用して最小差分で実装する。
5. 構文、import、未定義名、引数、戻り値、パス、データ項目、互換性、無関係な差分を静的確認する。
6. 関係する既存テストを実行し、既存環境と既存手順でアプリケーションを起動する。
7. 対象機能、主要な既存機能、標準出力、標準エラー、ログ、未処理例外を確認する。
8. エラー時は原因を切り分け、今回の変更範囲内の最小差分で修正し、同じ確認を再実行する。
9. 実装漏れ、不要変更、デバッグコード、不要ログ、一時ファイルを差分から確認する。
10. 調査結果、変更・追加ファイル、実装内容、確認結果、仮決め、未確認事項、人間の確認事項を報告する。

## 実装停止条件

不明点は既存実装から合理的に補完しますが、次の場合は変更を停止し「要確認」とします。

* 既存ファイルやデータの大量削除が必要。
* セーブデータや既存データの互換性を大きく失う。
* 主要システム全体の作り直しが必要。
* 選択肢により結果が大きく変わり、後から戻すことが困難。
* 外部サービスへの接続、公開、課金、認証情報が必要。
* ユーザーの既存変更を破棄する必要がある。
* 本番環境への変更が必要。

## 禁止事項

無関係なリファクタリング、既存変更の破棄、不要な依存関係の追加・更新、新規仮想環境の作成、無断のGit push・force push・外部公開・本番変更、秘密情報の表示を行いません。一時デバッグコードや毎フレーム大量に出るログを残しません。

## 完了報告形式

次の見出しで簡潔に報告します。

```text
調査結果
変更したファイル
追加したファイル
実装内容
動作確認結果
仮決め事項
未確認事項
人間が確認する内容
```
