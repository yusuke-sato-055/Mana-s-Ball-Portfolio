# Mana's Ball

Mana's Ball は、マナボールを運びながらキャラクターごとの能力とスキルを組み合わせて戦う、Python 製のターン制戦術スポーツゲーム・プロトタイプです。

本リポジトリは、エンジニア作品提出用のポートフォリオ版です。

> [!NOTE]
> 現行コードはボール保持・移動・攻撃・パス・スキルを扱う戦闘プロトタイプです。カード、手札、カードの役判定は現時点では実装されていないため、本 README では実装済みの内容だけを説明しています。

## 作品概要

プレイヤーはクエストを選び、味方パーティーを編成して、マス目状のフィールドで敵チームと対戦します。キャラクターは物理・魔法の系統と5種類の能力を持ち、移動、攻撃、パス、ボール奪取、回復・支援などを行います。スキルの使用可否や効果は、キャラクターの能力、MP、位置、ボール保持状態などから決まります。

戦闘はキャラクターの速度を基にした行動順で進みます。クエストごとにフィールド、敵グループ、出場人数、勝利条件、ターン上限などを組み合わせられる構成です。現在はゲームシステムと画面遷移を検証するプロトタイプ段階で、タイトル、クエスト選択、パーティー編成、戦闘、リザルトまで実装しています。

## 主な実装内容

- Python / Pygame によるデスクトップ向けゲームループと画面描画
- 13×5 マスのフィールドを使った人数可変のターン制戦闘
- ボール保持、移動、得点、通常パス、パスカット、スティール
- 物理・魔法攻撃、回復、強化、移動などの共通スキルシステム
- キャラクター、敵単体、敵グループ、スキル装備の管理
- 行動・位置取り・判断傾向をデータから切り替える敵 AI
- クエスト選択とパーティー編成、フィルター、並び替え、能力比較
- 浄化運搬、マナ奪還、儀式維持の3種類のクエストルール
- クエスト、フィールド、試合ルールを組み合わせる戦闘セットアップ
- 手動操作、オート進行、自由試合、ヘッドレスシミュレーション
- 画面内の戦闘ログと、試合結果を集計する Markdown レポート
- 戦闘ロジック、AI、セットアップ、UI を対象にした自動テスト

## 技術構成

| 要素 | 用途 |
| --- | --- |
| Python 3.11 | ゲームロジック、データ読み込み、起動処理 |
| Pygame 2 | 描画、入力、音声、ゲームループ |
| CSV | キャラクター、敵、AI、スキル、クエスト等のマスターデータ |
| JSON | フィールド配置と自由試合の一時設定 |
| `unittest` | 標準の自動テスト |
| pytest | 既存の `unittest` テストをまとめて実行できる任意のテストランナー |
| pygbag | PC と同じ処理をブラウザで試すための任意構成 |

通常起動に必要な外部ライブラリは Pygame だけです。CSV、JSON、テストの基本機能には Python 標準ライブラリを使用しており、pandas は使用していません。

## 起動方法

### 必要環境

- Python 3.11
- Windows、macOS、Linux のいずれかで Pygame のウィンドウを表示できる環境

### セットアップと起動

リポジトリ直下で次を実行します。

```bash
python -m pip install -r requirements.txt
python main.py
```

起動後は、ホーム画面の「クエスト」からクエスト選択、パーティー編成、試合開始の順に進みます。「自由試合」では敵グループ方式と敵手動編成方式を切り替え、人数、能力、スキル、AI、初期配置、先取点、ターン制限などを一時設定できます。

マウス操作に加え、pygbag 版ではタップを同じ座標変換と入力規則で処理します。音声素材がない場合は警告を出し、無音のままゲームを続行します。

## テスト

標準ライブラリだけでテストを実行する場合は次を使用します。

```bash
python -m unittest discover -s tests -v
```

pytest が導入済みの環境では、同じテストを次でも実行できます。

```bash
python -m pytest
```

画面初期化とデータ読み込みを含む短時間のスモークテスト、および AI 同士の無人試合も用意しています。

```bash
python main.py --smoke-test
python main.py --headless-sim
python main.py --headless-sim --enemy-group training_group --seed 7
python main.py --headless-sim --quest training_1v3 --seed 7
```

## データ管理

ゲームデータと処理を分離し、主な調整項目を `data/csv/` 以下で管理しています。

| ファイル | 内容 |
| --- | --- |
| `characters.csv` | プレイヤーキャラクターの能力とスキル枠 |
| `enemies.csv` | 敵単体の能力、スキル、既定AI |
| `enemy_groups.csv` | 敵の組み合わせ、倍率、個別AI |
| `ai_profiles.csv` | 攻撃、支援、ボール行動等の判断傾向 |
| `skills.csv` | スキルの使用条件、対象、コスト、分類 |
| `skill_effects.csv` | 1スキル最大5件の効果定義 |
| `quests.csv` | クエストとフィールド・ルール・敵グループの参照 |
| `field_settings.csv` | フィールド名、背景、BGM、レイアウト参照 |
| `match_rules.csv` | 出場人数、先取点、ターン上限、交代・負傷ルール |
| `match_settings.csv` | 共通計算値と互換用のデバッグ設定 |

`data/field_layouts.json` では、フィールドのサイズ、ゴール、出場位置、ベンチ位置などを管理しています。自由試合で保存した一時設定は `data/save/debug_match_last.json` に1件だけ保持されますが、マスターCSVは変更しません。

## 設計上のポイント

### 1. データ駆動の戦闘設定

キャラクター、敵、スキル、AI、クエストをCSVで管理し、`data.py` が入力値を検証して戦闘用オブジェクトへ変換します。能力や編成をコードへ大量に直書きせず、処理と調整データを分離しています。

### 2. 戦闘ロジックとUIの分離

`core.py` が移動可能範囲、成功率、ダメージ、ボール状態、得点、勝敗を確定し、`ui.py` は候補の選択、プレビュー、確定済み結果の表示を担当します。手動操作とAI操作は同じ `MatchGame` の判定経路へ接続します。

### 3. データ化したAIプロフィール

敵ごとのAIプロフィールとレベルをCSVから読み込み、攻撃、パス、得点、回復、奪取、危険許容などの重みとして行動候補の評価に利用します。敵グループ全体の既定値とスロット別の上書きを組み合わせられます。

### 4. クエストと試合ルールの合成

`battle_setup.py` がクエストIDを起点にフィールド、レイアウト、試合ルール、敵グループを結合します。同じ戦闘処理を、異なる人数・勝利条件・配置で再利用できる構造です。

### 5. ロジックと画面遷移を対象にしたテスト

テストでは攻撃、移動、パス、スキル、得点、AI、CSV互換、クエスト結合に加え、Pygame のダミードライバーを使った入力・画面遷移も確認します。ヘッドレス試合は固定シードで再現できます。

## 現行ゲーム仕様の補足

- フィールドは13×5マスで、左右に3×3マスのゴールがあります。
- 味方の手動ターンでは、現在行動者の周辺に「攻撃・移動・ボール・スキル・待機」を表示します。
- 移動後も攻撃、ボール行動、支援スキル、待機を選択できます。主行動確定前なら通常移動を取り消せます。
- 能力は物理系統・魔法系統と、パワー・マジック・スピード・テクニック・スタミナの5能力です。試合中に増減するリソースはHPとMPです。
- 通常クエストの勝利条件は、ゴールへの運搬、敵からの奪還、指定ターンの保持の3種類です。
- 標準の3対3以外にも、CSV設定に応じて1対1、1対3、4対4、6対6などを構成できます。パーティーはベンチを含め最大7枠です。
- 戦闘画面の「リタイア」は確認を経て試合を終了します。通常クエストでは敗北、自由試合ではデバッグ中断として扱います。

## ブラウザでの試遊（任意）

`pygbag.ini` を同梱しており、pygbag を別途導入するとPC版と同じゲーム処理をブラウザから実行できます。スマートフォンでは横向きを想定しています。

```bash
python -m pygbag --bind <PCのIPv4アドレス> --port 8000 .
```

同一ネットワーク上の端末から `http://<PCのIPv4アドレス>:8000/` を開きます。これは任意の試遊方法であり、通常起動用の `requirements.txt` には pygbag を含めていません。

## アセットについて

ゲームは `assets/fonts/NotoSansJP-VariableFont_wght.ttf` を日本語表示に使用します。キャラクターと敵の画像はCSV上のIDに対応するファイルを参照し、画像がない場合は簡易表示へフォールバックします。

画像・フォントの出典や利用条件をまとめたライセンス文書は、現時点のリポジトリ内では確認できません。公開・再配布前に、各素材が自作、AI生成、利用許可済み、または再配布可能であることを確認してください。
